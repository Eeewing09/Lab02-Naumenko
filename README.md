ПР2. Ответы на контрольные вопросы
1) Для хранения денег используют decimal, потому что он считает дроби со стопроцентной точностью, тогда как double допускает мелкие погрешности. double может просто испортить расчет, что нанесет большой ушерб
2) Отсчет переменной начнется сначала
3) В var тип определяется один раз при компиляции. Изменить его потом нельзя
В Python тип определяется во время работы программы и может свободно меняться на ходу
Компилятор определяет тип переменной, объявленной через var, в момент компиляции
4) Тип строки(string)
5) int.Parse - выдаст ошибку, а int.TryParse не сломает программу и выведет false
6) Значение false означает, что перевод текста в число провалился, а в out пойдет 0
7)  TryParse - когда мы не знаем что введет пользователь(число или цифру)
Parse - когда пользователь введет цифровое значение

Console.Write("Введите ваш возраст: ");
string input = Console.ReadLine();

//  Использование Parse (Плохо)
int age1 = int.Parse(input); 

bool success = int.TryParse(input, out int age2);
Здесь лучше использовать TryParse, так как пользователь может ввести текст
